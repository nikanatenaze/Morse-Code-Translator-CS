# ⚡ Morse Code Translator (C#)

> A simple and efficient Morse code translation utility written in C#.

---

## 📌 Overview

This project is a command-line application designed to translate standard text into Morse code and vice versa. It serves as a handy utility program for practicing logic, string manipulation, and mapping data structures in C#.

## 🛠️ Features

- **Text-to-Morse:** Converts standard alphanumeric characters into their corresponding Morse code sequences (dots and dashes).
- **Morse-to-Text:** Decodes Morse code inputs back into readable text.
- **Clean Implementation:** Straightforward logic using C# data structures for fast lookups.
